# Offcraft

[English](../../README.md)

Offcraft — мод для **Minecraft 1.21.1**, который позволяет управлять настоящим игровым клиентом из внешнего контроллера или через MCP. Игровое окно остаётся скрытым, а изображение можно получать в виде PNG.

Это не серверный бот и не полностью безграфический режим: клиенту по-прежнему нужны графическая сессия и рабочий OpenGL-драйвер.

## Возможности

- Список, создание и загрузка миров с seed/режимом/сложностью, переключение миров и подключение к серверам.
- Движение, спринт, прыжки, приседание, атака, использование/выбрасывание предметов, обмен рук и поворот через vanilla-механику.
- Управление инвентарём, контейнерами, интерфейсом и вводом текста.
- Состояние игрока, подробности выбранного предмета, виджеты GUI, полученные сообщения и цель под прицелом.
- Сохранение свежих игровых кадров в PNG и сокращённая фоновая отрисовка без остановки игровых тиков.
- MCP с изображениями по запросу и JavaScript SDK с необязательной ограниченной записью сессий.

## Требования и совместимость

| Компонент | Поддерживаемая конфигурация |
| --- | --- |
| ОС | Windows x64 |
| Minecraft | 1.21.1 |
| Java | 21 |
| Fabric Loader | 0.16.14 |
| Forge | 52.1.0 |
| NeoForge | 21.1.259 |
| MCP-адаптер, если используется | Node.js 22+ |

Для каждого загрузчика используется отдельный JAR. Дополнительные Fabric API, Architectury API или отдельный common-мод не нужны.

## Установка и управление

1. Подготовьте клиент Minecraft 1.21.1 с выбранным загрузчиком и Java 21.
2. Установите **только JAR своего загрузчика** в каталог `mods/`. Мод не запускается командой `java -jar` как самостоятельное приложение. Получение JAR из исходников описано в [руководстве по сборке](development.md).
3. Для Forge и NeoForge **до запуска** установите `earlyWindowControl=false` в `config/fml.toml` игрового каталога, сохранив остальные настройки. Иначе раннее окно загрузчика останется видимым.
4. Запускайте клиент через контроллер с доступом к stdin Java-процесса или через [MCP-адаптер](mcp.md). Обычный графический лаунчер может не предоставлять нужный поток ввода. Особенности запуска Forge описаны в [руководстве по запуску](development.md).

Управление передаётся командами JSON Lines. Контроллер должен дождаться готовности клиента и завершения предыдущей изменяющей команды; подтверждение принятия не означает выполнение. Форматы запросов и примеры находятся в [справочнике команд](protocol.md).

## Ограничения

- Offcraft не авторизует Microsoft-аккаунт и не обходит ограничения серверов. Development-запуск использует тестовый профиль.
- Действия следуют vanilla-механике: столкновения, задержки использования предметов и серверные правила остаются действующими.
- Наблюдение описывает клиентское состояние, а не отдельное подтверждение сервера.
- Скрывается игровое окно, но не обязательно терминал запуска; звук Minecraft не отключается.
- Sodium 0.6.9 и Iris 1.8.8 проверялись с Fabric. Совместимость сторонних renderer-модов Forge/NeoForge и любых shaderpacks не заявляется.
- Прежние проверки проводились в development-клиентах; они не подтверждают установку в обычный авторизованный лаунчер или запуск как Windows-службы.
