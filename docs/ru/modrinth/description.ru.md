# Offcraft

**Управляйте настоящим клиентом Minecraft через JSONL или MCP: скрытое игровое окно и свежие PNG-кадры.**

Offcraft — клиентский мод для **Minecraft Java Edition 1.21.1** с отдельными сборками для **Fabric, Forge и NeoForge**. Внешняя программа или MCP-клиент управляет игрой через обычный ввод и интерфейс Minecraft.

> **До установки:** Offcraft намеренно создаёт игровое окно скрытым. Это инструмент интеграции для разработчиков и контроллеров, а не мод для обычной игры в видимом окне. Контроллер должен запускать настоящий Java-клиент с доступом к stdin/stdout. Установка JAR в графический лаунчер сама по себе не создаёт контроллер; закрытие stdin запускает штатное завершение клиента.

## Возможности

- Создание и загрузка локальных миров, сохранение и переключение миров, подключение к серверам с профилем запущенного клиента.
- Движение, прыжки, приседание, атака, использование предметов, выбор слота хотбара и поворот камеры.
- Работа с инвентарём, контейнерами, GUI-клавишами, кликами мыши и Unicode-текстом через ванильные механики.
- Наблюдение состояния игрока, инвентаря, интерфейса и цели под прицелом.
- Запись свежего завершённого игрового кадра в PNG.
- Снижение частоты фонового рендеринга без остановки игровых и сетевых тиков.
- Подключение MCP-клиентов через stdio-адаптер Node.js без npm-зависимостей из репозитория исходников.

Длительность действий задаётся в игровых тиках, не миллисекундах. Завершение означает исполнение на клиенте, а не независимое подтверждение сервером. Offcraft не подменяет движение телепортацией, не записывает стеки контейнера напрямую, не авторизует Microsoft-аккаунты и не обходит ограничения сервера.

## Требования

- **Minecraft 1.21.1**, **Java 21**, **Windows x64**.
- Графическая сессия и рабочий OpenGL-драйвер даже при скрытом окне. Это **не полностью headless Minecraft** и не серверный бот.
- Один подходящий загрузчик: Fabric Loader **0.16.14**, Forge **52.1.0** или NeoForge **21.1.259** — закреплённые development-конфигурации.
- **Node.js 22+** только для необязательного MCP-адаптера.

Устанавливайте **только один** JAR Offcraft под загрузчик экземпляра игры. Fabric API, Architectury API, Sodium и Iris не требуются. Не устанавливайте Offcraft на выделенный сервер. Другие ОС, сторонние render-моды, установка через production-лаунчер и multiplayer-совместимость текущими проверками не подтверждены.

## Установка и запуск

1. Подготовьте отдельный клиентский экземпляр Minecraft 1.21.1 с Java 21 и нужным загрузчиком.
2. Положите подходящий `offcraft-1.0.0-mc1.21.1-<loader>.jar` в его каталог `mods/`. Source JAR предназначен для изучения исходников, не для установки.
3. **Forge / NeoForge:** до запуска задайте `earlyWindowControl=false` в `config/fml.toml` экземпляра, сохранив остальные настройки. Раннее окно загрузчика появляется до обнаружения модов; Offcraft не может скрыть его задним числом.
4. **Forge:** добавьте JVM-аргументы `-Dterminal.ansi=false -Dterminal.jline=false` для работы JSONL/stdin через pipes.
5. Запускайте настоящий Java-клиент из контроллера с pipes stdin/stdout и реальными JVM/main/game-аргументами загрузчика. `.bat` или графический лаунчер не заменяют Java-процесс. Не закрывайте stdin во время работы.
6. Дождитесь протокольного события `ready`, затем проверьте `status`. `ready` означает готовность принимать команды, не загрузку мира. При необходимости обработайте стартовые экраны GUI-командами.

[Руководство по сборке и запуску](https://github.com/mayorovyf/Offcraft/blob/main/docs/ru/development.md) описывает development-запуски и настройки загрузчиков. [Руководство MCP](https://github.com/mayorovyf/Offcraft/blob/main/docs/ru/mcp.md) содержит исполняемый пример development-запуска Fabric и требования к установленным клиентам.

## Пример JSONL

Передавайте по одному JSON-объекту в строке. Следующую команду мира или действия отправляйте только после терминального `completed` или `error` предыдущего ID:

```json
{"id":"world-1","command":"new","world":"controller-demo"}
{"id":"walk-1","command":"act","ticks":20,"buttons":["forward"],"capture":"output/after-walk.png"}
{"id":"status-1","command":"status"}
{"id":"quit-1","command":"quit"}
```

`accepted` не означает успех. Протокольные ответы содержат `protocol:1`; обычные логи Minecraft также идут в stdout/stderr и должны отличаться от ответов. Относительные PNG-пути считаются от рабочего каталога игры. EOF и `quit` освобождают управляемый ввод, сохраняют мир штатно и останавливают клиент.

## Совместимость и статус версии

Версия **1.0.0** подготовлена для канала **Beta**. Все три сборки включают одну общую игровую реализацию. Записанные проверки реальных development-клиентов охватывают загрузку миров, ввод, сохранение creative-инвентаря, capture, отмену и завершение. Они не подтверждают совместимость с любым лаунчером, сервером, драйвером или модпаком; доказательства и границы приведены в [журнале проверок](https://github.com/mayorovyf/Offcraft/blob/main/docs/ru/verification.md).

Используйте отдельные тестовые миры и резервные копии. Соблюдайте правила сервера об автоматизации.
