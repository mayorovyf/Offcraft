# Техническая документация Offcraft

[English](../README.md)

[Пользовательский обзор](README.md) · [Инструкции агентам](AGENTS.md)

Команды в документации рассчитаны на Windows / PowerShell, кроме явно помеченных примеров Bash в руководстве Git. Относительные пути исходников считаются от корня репозитория.

| Документ | Когда читать |
| --- | --- |
| [spec.md](spec.md) | При внедрении Offcraft в существующее приложение или MCP-хост |
| [architecture.md](architecture.md) | Перед изменением общего кода, mixins, потоков, ввода, capture или границ загрузчиков |
| [development.md](development.md) | Для сборки, запуска, обновления версий, настройки раннего окна и Fabric renderer-профилей |
| [protocol.md](protocol.md) | При работе с JSONL-командами, ошибками, состоянием мира, GUI и инвентарём |
| [mcp.md](mcp.md) | При подключении MCP, изменении схем, транспорта, корреляции ID или отмены |
| [verification.md](verification.md) | Для выбора проверок, smoke-сценариев и понимания границ исторических результатов |
| [standalone.md](standalone.md) | Для корневого Maven/LWJGL-стенда, отдельного от Minecraft-модов |
| [git.md](git.md) | До операций с ветками, коммитами, интеграцией, тегами или публикацией |
| [modrinth.md](modrinth.md) | Для готового оформления Modrinth, отдельных loader-загрузок, изображений и локального комплекта |

Подробные контракты и инструкции хранятся здесь. В корневом README остаётся пользовательский обзор; в AGENTS.md — только постоянный контекст и обязательные инварианты.

Основные документы ведутся на английском. Русские версии, включая пользовательский обзор и инструкции агентам, находятся в `docs/ru/`; обновляйте оба языка вместе.
