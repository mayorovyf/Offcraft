# Архитектура и инварианты

[English](../architecture.md)

[Документация](index.md) · [Обзор проекта](README.md)

Minecraft-мод для Windows x64, Java 21 и **Minecraft 1.21.1**, с отдельными сборками Fabric, Forge и NeoForge:

- `common/` — единая реализация JSONL, игровых действий, GUI, наблюдения, framebuffer capture и клиентских mixins; пакет `offcraft.client`.
- `fabric/`, `forge/`, `neoforge/` — bootstrap и метаданные соответствующего загрузчика. Каждый JAR включает common, дополнительный common-мод не устанавливается. Runtime Architectury API не требуется.
- Корневой Maven-проект — диагностический LWJGL 3.3.6 стенд с треугольником, скрытым GLFW-окном и framebuffer 640×360.

`mcp/` — отдельный stdio MCP-адаптер на Node.js 22+, запускающий настоящий клиент и переводящий MCP-запросы в игровой JSONL. Системный оконный объект клиента существует, но не показывается; графическая сессия и рабочий OpenGL-драйвер всё ещё нужны.

## Границы модулей

Каждый загрузчик компилирует `../common/src/main/java` и включает `../common/src/main/resources`. Игровые возможности реализуются в common, а не дублируются в bootstrap загрузчиков. Корневой Maven не собирает моды; общий код не является отдельным Gradle-проектом. MCP запускает реальный executable без shell, не подменяет игровой процесс.

Новые наблюдения выполняются по запросу; в моде нет сканирования мира, навигации, интерпретатора макросов и видеопотока. Только показанные сообщения добавляются в ограниченный журнал. `press` использует один тик vanilla drop/swap; полный сброс стека меняет Control query только во время подготовленного тика ввода. Освобождение включает sprint/drop/swap. Node.js читает явно завершённые захваты для MCP-изображений, использует существующий bridge в SDK и записывает протокол только при включении. PNG по-прежнему записывается синхронно на render thread; частые захваты требуют измерений, а не заявления о производительности.


## Скрытый режим

- Mixin перехватывает `glfwDefaultWindowHints`, выполняет исходный сброс, затем устанавливает `GLFW_VISIBLE`, `GLFW_FOCUSED`, `GLFW_FOCUS_ON_SHOW` в false и отключает fullscreen. Этот redirect не конкурирует с перехватом `glfwCreateWindow` в Sodium и допускается constructor-инъекциями Forge Mixin. Окно не скрывается постфактум; раннее окно Forge/NeoForge отдельно отключается настройкой из [руководства по запуску](development.md).
- Внутреннее начальное состояние клиента — без фокуса. Автопауза при потере фокуса выключена; захват и перемещение курсора игрой запрещены.
- stdin читает daemon-поток, ограниченная очередь содержит 32 строки. Команды выполняются на render thread; игровые кнопки выставляются перед обработкой ввода каждого тика и считаются после завершения тика. По завершении, прерывании, `quit`, EOF и остановке очищаются все управляемые кнопки и очереди нажатий. Toggle-sneak и переназначение физических клавиш не меняют логические действия контроллера.
- Закрытие экрана снимает vanilla-блокировку атаки от GUI перед возобновлением управляемого ввода; обычные cooldown атаки сохраняются, дополнительный нейтральный тик действия и захват курсора не нужны.
- По умолчанию `reduced`: цикл клиента ограничен 30 итерациями/с, дорогая отрисовка мира — 2 кадрами/с; игровые и сетевые тики продолжаются. `render` и завершение действий/GUI требуют свежего кадра. Меню и загрузочный overlay не пропускаются. `normal` возвращает постоянную отрисовку с сохранённым FPS-лимитом, но не ниже 20; `fps` настраивает только reduced-отрисовку, фактический потолок — частота цикла. Это не полное demand-rendering standalone-стенда.
- Считывается цветовая текстура игрового framebuffer через Minecraft `NativeImage`, строки переворачиваются. NativeImage переиспользуется до изменения размера; привязка текстуры восстанавливается после чтения. PNG записывается синхронно на render thread и на время записи задерживает кадр.
- Размер development-окна по умолчанию 640×360; сохранённые настройки размера Minecraft могут его переопределить. Снимок использует фактический размер framebuffer.
- Терминал запуска остаётся видимым. Звук Minecraft не отключается. Для запуска без новой консоли контроллер должен запускать Java с перенаправленными потоками и соответствующими Windows-параметрами процесса.

## Контракты, которые нельзя терять

- GLFW/OpenGL и изменения Minecraft выполняются на клиентском render thread; поток stdin только передаёт строки в очередь.
- Длительность действий — клиентские игровые тики. Ввод остаётся vanilla; движение не заменяется телепортацией, стеки — прямой записью.
- Завершение, прерывание, отмена, EOF и shutdown освобождают удерживаемые кнопки и queued presses.
- `accepted` не означает успех. Терминальный ответ долгой команды связан с фактической готовностью мира, завершением действия или записью PNG.
- Свежий снимок делается после отрисовки; reduced-режим не останавливает тики и сетевое обслуживание.
- Клиентское наблюдение и локальное предсказание не выдаются за серверное подтверждение.

Подробные форматы и ошибки: [JSONL](protocol.md). Изменения MCP требуют синхронизации со [схемами и адаптером](mcp.md).
